Gallery is the local library for Herm eikons. It lists bundled eikons and eikons installed under the active Hermes home.

Open it with **Alt+5** and the **Gallery** sub-tab, or type `/gallery`.

## What the list shows

The list focuses on eikon names and active state. The details pane shows richer metadata for the selected entry, including author, local status, source availability, package identity, and trust/status labels when available.

The preview pane renders the selected eikon. If Herm cannot render a preview, it shows a fallback message instead of crashing the tab.

## Activate an eikon

Select a row and press `Enter`. Herm saves that eikon name as the active avatar and updates the sidebar.

## Create or install an eikon

Press the configured `list.new` key, usually `n`, to open the **New / Install** dialog.

You can:

- create a blank local eikon draft
- create a draft from local source media
- inspect and install a supported package source

Current source install flows are GitHub-package oriented. Use Marketplace for the default public catalog.

## Gallery actions

| Key | Action |
|---|---|
| `Enter` | Activate the selected eikon |
| `n` | Create or install an eikon |
| `e` | Edit the selected eikon in Studio |
| `u` | Update a non-bundled installed eikon |
| `s` | Submit a local draft to the official registry |
| `d` | Delete a local non-bundled eikon |
| `/` | Search the list |

<Warning>
  Deleting an eikon removes local files. Bundled eikons cannot be deleted from Gallery.
</Warning>

## Submit a local draft to the official registry

Press `s` on a non-bundled local eikon to open the **Submit eikon** dialog. Submitting opens a pull request against the official Eikon registry; it does not activate or change the selected eikon.

<Steps>
  <Step title="Fill in public metadata">
    The dialog prompts for four fields that become the eikon's public identity:

    - `title` — display name in the catalog
    - `author` — credit shown on the listing
    - `description` — short one-line summary
    - `glyph` — one or two terminal-safe characters used as a marker

    Defaults are inferred from the local artifact and your GitHub identity when available. Use `Tab` and `Shift+Tab` to move between fields. Values that contain control characters, look secret-like (tokens, credentials, private keys), or point at private or unsafe URLs are rejected before preflight.
  </Step>
  <Step title="Preview the public bundle">
    Press `Enter`. Herm runs the registry preflight, which builds a staged copy of the public submission bundle: the gzip-normalized runtime, the package manifest, generated package blobs, and the merged `eikons/index.json` catalog entry. The dialog lists the included files, the target repository, the generated PR title and body, the manual fallback URL, and the staged bundle path you can open from the dialog.

    Editing any metadata field invalidates the staged bundle so the next submit rebuilds it.
  </Step>
  <Step title="Consent and submit">
    Press `c` to record consent to publish the listed files. Then press `Enter` to submit through the GitHub backend. Herm forks the registry repo if needed, creates a `submit/<name>` branch, uploads the staged files, and opens the PR.

    If GitHub authentication is missing or the backend call fails, Herm keeps the staged bundle and surfaces a browser fallback. Press `o` to open the prepared compare URL, then follow the listed manual steps to push the staged bundle and open the PR by hand. Press `Esc` to cancel; cancelling cleans up the staged bundle unless a fallback is in progress.
  </Step>
</Steps>

<Note>
  The staged bundle strips unknown manifest fields and stores the public metadata under a `display` block. Source media is not included by default — only the runtime artifact and registry package contract files ship in the PR.
</Note>

## When to use Studio or Marketplace

Use **Studio** when you want to edit source media, tune rasterizer settings, or render state frames.

Use **Marketplace** when you want to browse the shared catalog, install a package, download source when the package provides it, or activate an already-installed catalog entry.
